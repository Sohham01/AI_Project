    Decision boundaries

    • Advice vs solution: advice is general guidance (“reach out to seniors”). solution is a concrete, actionable fix. Set is_solution to solution whenever a comment supplies a concrete remedy, even when its primary response role is advice or personal_experience.
    • Empty multi-label sets are valid: Plain factual replies (“Yes, 92 percentile”) can carry zero emotions and zero issue domains. Leave optional groups blank rather than forcing a guess.
    • Adjudication routing: Use uncertain when borderline, abstain when parent context is missing or untranslatable, and excluded for AutoModerator boilerplate or GIF embeds.
    • Thread-balanced ordering: Default order rotates across threads and subreddits so your first 60 to 100 annotations span 30 or more distinct threads for leakage-free splits.
