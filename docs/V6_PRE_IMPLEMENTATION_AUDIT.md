## 3. Execution Roadmap (Strict Phase Order)

1. **Phase 1:** Install & verify official `bertopic`, `umap-learn`, `hdbscan`, `sentence-transformers`; implement `ml/topics/bertopic/` alongside untouched NMF; benchmark Multilingual E5, Multilingual MiniLM, LaBSE, and MuRIL-DAPT-WWM pooled embeddings; persist `ml/artifacts/topic_models/bertopic_v1/` + registry; integrate NMF vs. BERTopic toggle in `/api/demo/topics` & `Topic Map`; write `docs/BERTOPIC_IMPLEMENTATION_AND_COMPARISON.md`.
2. **Phase 2:** Upgrade `indian_reddit_lid.py` with span/sentence-level LID, explicit uncertainty/abstention, and Romanized Hindi/Bengali/Odia phonetic-variant normalization; build a manually reviewable real-comment evaluation set (separate from synthetic multilingual probes); write `docs/MULTILINGUAL_PROCESSING_EVALUATION.md`.
3. **Phase 3:** Build context-aware slang/emoji normalization (`mid`, `based`, `cooked`, Indian expressions, affect emojis) with transformation metadata; benchmark all 5 classification tasks across `(A) Original`, `(B) Slang`, `(C) Emoji`, `(D) Slang+Emoji` strictly on 5-fold OOF CV; write `docs/SLANG_EMOJI_ABLATION.md`.
4. **Phase 4:** Build contextual multilingual-embedding **Issue–Solution Mapping Engine** (`ml/linking/`) with negation/contradiction penalty, parent context, semantic solution clustering, and human-reviewable Precision@k / Recall@k / MRR / NDCG@k evaluation; integrate into `Issues` & `Resolution`; write `docs/ISSUE_SOLUTION_MAPPING_REPORT.md`.
5. **Phase 5:** Formalize explainable resolution scoring (`reported_success`, `reported_pending`, `proposed_only`, `insufficient_evidence` + contradictory follow-up detector + time elapsed + evidence trail) and human-reviewed evaluation sample; integrate into `Resolution`; write `docs/UNRESOLVED_ISSUE_METHODOLOGY.md`.
6. **Phase 6:** Audit & reconcile strict OOF-only selection numbers vs. post-hoc `v6.1.0` transparently in `docs/V5_MODEL_IMPROVEMENT_REPORT.md` and `Models & Data` view (zero test-set peeking claims).
7. **Phase 7:** Upgrade `cross_model_insights.py` + `Overview` into an **Evidence-Linked Insight Explorer** separating observations, interpretations, supporting `post_id`/comment quotes, topic/issue refs, confidence, and limitations; write `docs/CROSS_MODEL_INSIGHT_ENGINE.md`.
8. **Phase 8:** Complete full 9-view UI integration, API backward compatibility checks, and slim Vercel zero-ML runtime audit.
9. **Phase 9:** Compile consolidated `docs/academic_submission/` deliverables (Deliverables 1–6) and run full QA (unit/integration/reproducibility tests, Docker build, browser verification — zero unsolicited commit/push/deploy).
